🎯 System Overview

What This System Does

A comprehensive data management system that replaces Excel-based sales operations with a robust PostgreSQL database and REST API. All your Excel formulas, calculations, and business logic are preserved and enhanced with real-time capabilities.

Architecture

  • Database Layer: PostgreSQL with 9 tables, views, triggers, and stored procedures
  • API Layer: FastAPI backend with automatic OpenAPI documentation
  • Data Migration: Automated script to import from Excel to SQL
  • Business Logic: SQL views replicate all Excel formulas and calculations

🗄️ Database Schema

Core Tables

Table Description Key Fields
salespeople Master table for sales team members ID, Name, Role (Hunter/Farmer), Email, Joining Date
customers Master table for all customers ID, Name, Industry, Hunter ID, Farmer ID, Status
products Product catalog with pricing ID, Name, Category, Base Price, Description
invoices All revenue transactions ID, Customer, Date, Amount, Quarter, Category (Net New/Retention)
collections Payment tracking for invoices Invoice ID, Amount, Payment Status, Days Outstanding
agreements Customer contracts ID, Customer, Start/End Date, Contract Value
deals Sales pipeline (HubSpot) ID, Name, Stage, Amount, Expected Close Date
customer_targets Quarterly targets by customer Customer ID, Fiscal Year, Q1-Q4 Targets (Net New/Retention)
salesperson_targets Quarterly targets by salesperson Salesperson ID, Fiscal Year, Q1-Q4 Targets (Net New/Retention)

Key Views (Business Logic)

  • vw_customer_quarterly_achievements - Complete customer performance with all quarters
  • vw_salesperson_quarterly_achievements - Complete salesperson performance with all quarters
  • vw_dashboard_metrics - Executive KPIs and summary statistics
  • vw_collections_summary - Payment tracking with full context

Automatic Calculations

  • GST = Amount × 0.18 (auto-calculated)
  • Total Amount = Amount + GST
  • Quarter derived from invoice date (Fiscal year starts April)
  • Achievement % = Achievement ÷ Target × 100
  • Gap = Achievement - Target
  • Days Outstanding = Current Date - Invoice Date
  • Collection Efficiency = Amount Collected ÷ Invoice Amount
  • Tenure = Months since joining date

⚙️ Setup Guide

Prerequisites

  • PostgreSQL 12+ installed and running
  • Python 3.8+ installed
  • Excel file: Neelam's Data Sheet (2).xlsx

Quick Start (5 minutes)

Step 1: Install Python dependencies
pip install -r requirements.txt

Step 2: Initialize database
cd database
chmod +x init_database.sh
./init_database.sh

Step 3: Migrate data from Excel
cd ../backend
python3 migrate_data.py

Step 4: Start API server
python3 app.py

Step 5: Access the API
Open browser: http://localhost:8000/docs

💡 Usage Examples

SQL Queries

Top 5 Salespeople by Q2 Achievement:

SELECT name, role, q2_total_ach, q2_ach_pct
FROM vw_salesperson_quarterly_achievements
WHERE fiscal_year = 2025
ORDER BY q2_ach_pct DESC
LIMIT 5;

Customers Below 80% Target:

SELECT client_name, ytd_total_target,
       ytd_total_ach, ytd_gap, ytd_ach_pct
FROM vw_customer_quarterly_achievements
WHERE fiscal_year = 2025 AND ytd_ach_pct < 0.8
ORDER BY ytd_gap ASC;

Overdue Collections:

SELECT client_name, invoice_id,
       invoice_amount, balance_outstanding,
       days_outstanding
FROM vw_collections_summary
WHERE payment_status = 'Overdue'
ORDER BY days_outstanding DESC;

Revenue by Quarter:

SELECT quarter,
       SUM(CASE WHEN revenue_category = 'Net New'
           THEN amount ELSE 0 END) as net_new,
       SUM(CASE WHEN revenue_category = 'Retention'
           THEN amount ELSE 0 END) as retention,
       SUM(amount) as total
FROM invoices
WHERE fiscal_year = 2025
GROUP BY quarter
ORDER BY quarter;

Python Integration

import requests

# Get dashboard metrics
response = requests.get('http://localhost:8000/api/dashboard/metrics')
metrics = response.json()

print(f"Total Customers: {metrics['total_customers']}")
print(f"Q2 Achievement: {metrics['q2_team_ach_pct']:.1%}")

# Get salesperson performance
response = requests.get(
    'http://localhost:8000/api/analytics/salesperson-achievements',
    params={'fiscal_year': 2025}
)
salespeople = response.json()

for person in salespeople:
    print(f"{person['name']}: {person['ytd_ach_pct']:.1%}")
